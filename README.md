# Spartan App – IC2IE 2026

This repository contains the source code and supplementary
materials for the research paper:

"Analysis of a Web-Based Activity and Attendance Management System:
A Case Study of the Spartan App"

## Research

Authors:
- Dimmitry Dyllan Octavian Sutedjo
- Pandu Wicaksono

Affiliation:
Computer Science Department
Bina Nusantara University

## Purpose

This repository provides supplementary technical materials
used in the analysis of the Spartan App, particularly for
the source-code analysis involving Lines of Code (LOC)
and Cyclomatic Complexity.

## Source Code Analysis

The source-code analysis reported in the paper includes:

- Lines of Code (LOC)
- Cyclomatic Complexity
- Source-code structure analysis

The analysis reported:

- 11,679 LOC
- 86 source files
- 1,048 total Cyclomatic Complexity
- 84 files analyzed for Cyclomatic Complexity
- Average Cyclomatic Complexity: 12.48
